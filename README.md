# Python on Vercel Academy

GitHub repo: [vercel-labs/academy-python-course](https://github.com/vercel-labs/academy-python-course)

This folder combines both student code states for the course:

- `starter/` is the project students begin with.
- `complete/` is the finished reference implementation.

Each project has the same structure:

- Next.js app at the root (`app/`, `package.json`, `next.config.ts`)
- FastAPI backend in `api/index.py`
- Python dependencies in `pyproject.toml`

## Usage

Start from `starter/` while following lessons. Use `complete/` only as a reference if you need to compare your work.

## Skill

This repo includes a project skill at `.cursor/skills/academy-python-course/SKILL.md`.

Use it as a course companion when you want help with:

- `vercel dev` setup and debugging
- FastAPI route matching in `api/index.py`
- Wiring `app/page.tsx` to `/api/items`
- Deployment verification and common errors
